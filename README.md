## Descripción del Proyecto

Este proyecto consiste en el **diseño y desarrollo de una plataforma de interconexión y prueba para el microcontrolador Siwa**.  
La plataforma permitirá conectar, programar y verificar el funcionamiento del microcontrolador mediante el diseño de un circuito electrónico, la creación del esquemático y el desarrollo de una tarjeta de prueba (PCB).

El proyecto incluye además la validación del diseño antes de fabricación (DFM), el ensamblaje de la tarjeta, la carga del programa en el microcontrolador, la verificación de su funcionamiento y la caracterización de su consumo de potencia.
